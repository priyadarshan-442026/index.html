# Smart Laundry Service - Week 3 JavaScript Project

## Project Description

Smart Laundry Service is a responsive web application developed using HTML, CSS, and JavaScript. The project demonstrates how JavaScript can be integrated into a static webpage to improve user interaction and provide a better user experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Features

- Responsive Navigation Bar
- Hero Section
- Learn More Button
- Dark Mode Toggle
- Live Digital Clock
- Interactive Service Cards
- Customer Motivation Quote Generator
- Counter Application
- Contact Form Validation
- Scroll to Top Button
- Smooth Scrolling
- Hover Effects
